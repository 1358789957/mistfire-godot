# 雾火神殿 · Godot 切片

俯视 3D 的 Mistfire Sanctum 可玩切片（Godot 4.7）。砍树、点祭坛、建火塔/骨祠、占城寨、守夜三波。

手机网页版在另一个仓库：[mistfire-sanctum](https://github.com/1358789957/mistfire-sanctum)。这份是桌面 Godot 工程。

## 怎么开

Godot 4.7 打开本目录，或：

```bash
godot --path . --rendering-driver opengl3
```

`run.sh` 是软件渲染启动脚本（无独显时用）。

## 操作

- WASD 移动，鼠标转向
- Space 攻击 / 按住砍树
- E 点祭坛、开箱子
- B 切换建造（火塔 / 骨祠），F 放下，R 旋转
